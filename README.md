# Google Developers Group

https://gdgjf.github.io

Este é um projeto [Next.js](https://nextjs.org) gerado pelo [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Rodando o projeto

Após clonar o projeto, instale as dependências com `yarn install`

```bash
git clone git@github.com:gdgjf/gdgjf.github.io.git
cd gdgjf.github.io
yarn
yarn dev
```

Abra [http://localhost:3000](http://localhost:3000) em seu navegador para ver o projeto local.

## GitHub Pages

Esse projeto é distribuído através do GitHub pages. Acesse o arquivo [deploy.yml](./.github/workflows/deploy.yml) para ver como a integração faz o build do projeto e o distribui para https://gdgjf.github.io
